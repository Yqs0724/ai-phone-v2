# PRD-00 · AI 小手机 v2 项目总览

> 一句话叙事：**从"记得你"到"聊不腻"**——v1 攻克记忆与主动性，v2 攻克同质化。

## 产品定位

一个"记得你、会主动、聊不腻"的 AI 陪伴应用。核心差异点：剧情弹药库——把用户散落的收藏（剧情点子/角色卡/Prompt 技巧）结构化为素材库，在剧情平淡时按当前人设供给差异化桥段。

## 模块地图

```
对话核心（四层注入：人设→演法规范→姿态→记忆）
├── 长期记忆：提炼 / 注入 / 衰减 / 取舍 ────────┐
├── 剧情姿态 + 主动消息 + 纪念日                 │
└── 剧情弹药库 ⭐v2 新增                         │
      入库打标 → 素材库检索 → 给梗 ←────────────┘
        （记忆系统为给梗去重，防重复推荐）
```

## 技术栈与架构纪律

React + TS + Vite + Tailwind v4 ｜ Node(Express) + SQLite(node:sqlite) ｜ DeepSeek API ｜ PWA
- `server/src/services/llm.js` 是唯一 API 出口；`server/src/db.js` 是唯一 SQL 入口
- 功能按模块自包含，逐模块验收后推进
